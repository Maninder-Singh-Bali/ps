Your local studio

Source review checkout: runtime bundles and model weights are not included. See SOURCE_SETUP.md in the repository. The package instructions below apply to an installed distribution.

Double-click Launch Pixeloid Studio.cmd in the dashboard folder. It opens in your normal browser. Codex, cloud accounts and API keys are not required.

What is included

The dashboard, Python runtime, image and video readers, PDF importer, vector drawing engine, prompt preparation, scene checks, progress tracking and FLUX/LTX workflow templates are stored with the application. Keep the runtime and vendor folders beside server.py.

Your renderer

FLUX and LTX use your existing local ComfyUI installation and its model files. Startup reuses a running server. If none is running, the launcher can start the configured installation. It never stops a shared renderer. Change installation paths in studio.local.json if you move ComfyUI.

If something stops

Open System check. It reports missing components, models and saved files. Activity shows errors for individual jobs. Restarting the dashboard reconnects to acknowledged render jobs; it does not blindly submit them again. Ambiguous submissions need inspection before retrying. Your source files and previous outputs are retained.

Review is part of the workflow

Confirm the room map, then review the generated image before making video. A protected image edit preserves and checks the pixels outside its selected area. That does not guarantee an exact product replica or rigid geometry throughout generated video. Watch the entire clip before approving.

Offline and online

Local files, drawing, prompts, images and videos work offline once models are installed. Online furniture discovery and website imports require internet. Pinterest is inspiration; a retailer listing is needed to verify a purchasable product. No purchase is made by the dashboard.
